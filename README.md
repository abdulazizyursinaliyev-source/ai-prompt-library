# AI Prompt Library

> Professional, ready-to-use AI prompts for **images**, **videos**, and **code** — copy, paste, generate.

If this helped you, leave a star - it helps others find it too.

## Contents

| Folder | What's inside |
|---|---|
| prompts/image-prompts.md | Product & marketing image prompts (Nano Banana, Midjourney, SDXL) |
| prompts/video-prompts.md | Ad/reels video prompts (Google Veo / Gemini formula) |
| prompts/code-prompts.md | Prompts for AI coding assistants - build a website, bot, or app from one message |

## Why this exists

Most prompt collections are vague one-liners. These are structured, field-tested templates built around real formulas (cinematography + subject + action + context + style for video; strict copy rules for product images; clear spec prompts for code).

## Usage

1. Open the relevant file
2. Copy a template
3. Replace the bracketed placeholders [LIKE THIS] with your details
4. Paste into your AI tool (Gemini, Veo, Midjourney, Claude, Copilot, ChatGPT)
