# Code Prompts

For AI coding assistants (Claude, Copilot, ChatGPT). The key to good results: describe the OUTCOME and CONSTRAINTS, not implementation details.

## Landing page / website

> Build a one-page website for [BUSINESS NAME], a [BUSINESS TYPE]. Sections: hero with headline and CTA button, product/service grid, about section, contact form, footer with social links. Mobile-friendly, modern clean design, color theme: [COLOR]. Use plain HTML/CSS/JS, no build tools.

## Telegram/Instagram auto-reply bot

> Build a bot that replies automatically to messages containing [KEYWORDS, e.g. price, delivery, order]. For each keyword, reply with [RESPONSE TEXT]. If no keyword matches, forward to a human. Log every conversation.

## Simple calculator / tracker app

> Build a single-page app that tracks [WHAT - e.g. truck expenses and income]. Fields: date, description, amount, type (income/expense). Show a running total and a simple monthly summary. Store data locally in the browser, no backend needed.

## Fixing a bug (use with existing code)

> Here is my code: [PASTE CODE]. It should [EXPECTED BEHAVIOR] but instead [ACTUAL BEHAVIOR]. Find and fix the bug, explain what was wrong in one sentence.

## Rule of thumb

The more specific your constraints (what it must NOT do, what tools/format you want), the better the first result - less back-and-forth.
